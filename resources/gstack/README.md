# GStack

> 本页依据 [GStack 原仓库](https://github.com/garrytan/gstack) 整理；Skill 名称和工作流以原仓库为准。

## 它解决什么问题

GStack 把产品思考、架构、设计、实现、代码审查、QA、安全和发布等角色组织成可衔接的 AI 编程 Skills，减少直接跳进编码造成的返工。

## 核心能力

- 从需求澄清和产品判断开始组织开发
- 串联架构、设计、实现与代码审查
- 把 QA、安全和发布检查纳入交付流程
- 允许按任务选择需要的角色与 Skill

## 适合谁

适合希望建立完整 AI 开发流程的个人开发者、产品工程师和小型软件团队。

## 使用前要知道

工作流会增加前期步骤，简单修改不一定需要全部角色。应按风险选择合适的 Skill，并以测试和代码审查作为最终验证。

## 上游明确提供的接入方式

上游以 Claude Code 为主要宿主，同时安装器明确支持 Codex CLI 并生成对应 Skills。
