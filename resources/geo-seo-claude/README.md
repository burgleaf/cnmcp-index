# GEO SEO Claude

> 本页依据 [GEO SEO Claude 原仓库](https://github.com/zubair-trabzada/geo-seo-claude) 整理；方法与安装说明以原仓库为准。

## 它解决什么问题

GEO SEO Claude 把生成式搜索优化、技术 SEO、内容分析、结构化数据和客户报告拆成多组 Skill 与子智能体，适合执行较完整的网站可见性审计。

## 核心能力

- 分析网站面向搜索引擎和生成式答案系统的可见性
- 检查技术 SEO、内容结构与结构化数据
- 组织研究、审计和客户报告工作流
- 通过多个专用 Skill 分担不同分析任务

## 适合谁

适合 SEO 顾问、营销团队、内容负责人和负责网站质量的 Web 开发者。

## 使用前要知道

GEO 仍是快速变化的领域，工具输出应结合真实流量、索引和转化数据判断，不能保证排名或被生成式答案引用。
