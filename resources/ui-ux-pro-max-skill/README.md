# UI UX Pro Max

> 本页依据 [UI UX Pro Max 原仓库](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 整理；设计资料和技术栈覆盖以原仓库为准。

## 它解决什么问题

UI UX Pro Max 为 AI 编程助手提供界面设计规则、行业模式、配色、字体和前端技术栈指导，帮助从模糊需求更快得到一致、可实现的 UI 方案。

## 核心能力

- 根据行业与页面目标选择设计模式
- 提供配色、字体、版式和组件建议
- 覆盖多种前端技术栈的实现指导
- 将可访问性和界面质量规则带入生成过程

## 适合谁

适合设计师、前端开发者，以及需要快速构建产品页面、后台或营销网站的团队。

## 使用前要知道

规则库提供的是起点，不是品牌策略。正式发布前仍需结合真实内容、设计系统、可访问性检查和用户测试。

## 上游明确提供的接入方式

上游提供 Claude Code 插件市场与 Skill 安装方式，配套 CLI 也明确支持 Codex 并生成对应 Skill 目录。
