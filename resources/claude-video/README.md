# Claude Video

> 本页依据 [Claude Video 原仓库](https://github.com/bradautomates/claude-video) 整理；依赖和支持格式以原仓库为准。

## 它解决什么问题

Claude Video 让 AI 编程助手读取视频字幕与关键帧，并结合时间戳回答内容分析、教程定位和故障诊断问题。

## 核心能力

- 提取或读取视频字幕
- 按时间抽取关键帧并结合画面理解内容
- 根据问题定位相关片段与时间戳
- 用于内容总结、剪辑研究和操作故障分析

## 适合谁

适合需要快速理解长视频的导演、影视从业者、内容创作者、研究者和技术支持人员。

## 使用前要知道

视频处理可能依赖本地媒体工具并占用较多存储和计算资源。处理受版权或保密约束的素材前，应确认使用权限和数据去向。

## 上游明确提供的接入方式

上游提供 Claude Code 插件市场安装方式，同时提供 Agent Skills CLI 与 Codex 插件清单，并明确列出 Codex。
