# Hallmark

> 本页依据 [Hallmark 原仓库](https://github.com/Nutlope/hallmark) 整理；设计规则与安装方法以原仓库为准。

## 它解决什么问题

Hallmark 是面向网页设计的 Agent Skill，通过主题、字体、版式和视觉工艺规则，减少 AI 页面常见的模板化和千篇一律感。

## 核心能力

- 在实现前建立明确的视觉方向
- 指导字体、色彩、层次和间距选择
- 约束容易出现的通用 AI 视觉套路
- 帮助生成更有辨识度的网页界面

## 适合谁

适合设计师、前端开发者，以及希望快速获得更成熟视觉方向的产品团队。

## 使用前要知道

设计规则不能替代品牌研究、真实内容和用户测试。结果仍需检查可访问性、响应式表现和产品一致性。
