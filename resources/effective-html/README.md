# Effective HTML

> 本页依据 [Effective HTML 原仓库](https://github.com/plannotator/effective-html) 整理；Skill 清单与示例以原仓库为准。

## 它解决什么问题

Effective HTML 提供一组生成自包含 HTML 成果物的 Agent Skills，让报告、线框图、交互原型、计划和架构图既可直接查看，也便于验证和分享。

## 核心能力

- 生成结构清晰的报告与计划页面
- 构建线框图和可交互原型
- 用 HTML 表达架构、流程和复杂关系
- 强调单文件、自包含与可验证输出

## 适合谁

适合需要快速产出可视化方案的设计师、产品经理、开发者，以及希望把 AI 结果交给他人审阅的团队。

## 使用前要知道

生成页面仍需检查可访问性、响应式布局和浏览器兼容性。涉及真实产品时，不应把原型直接当作生产代码发布。

## 上游明确提供的接入方式

上游提供 Claude Code 和 Codex 的插件市场方式，也保留独立 `SKILL.md` 的安装路径。
