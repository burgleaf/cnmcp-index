# I Have ADHD

> 本页依据 [I Have ADHD 原仓库](https://github.com/ayghri/i-have-adhd) 整理；行为规则以原仓库为准。

## 它解决什么问题

I Have ADHD 用行动优先、编号步骤、限制旁支和减少信息噪声等规则约束 AI 编程助手，让回答更容易开始、执行和完成。

## 核心能力

- 把建议转换成短小、编号且可执行的步骤
- 优先呈现当前动作，减少不必要的背景展开
- 控制旁支和选择数量，降低决策负担
- 鼓励明确完成条件和下一步

## 适合谁

适合容易被长回答、并行选项或模糊任务阻碍的开发者，也可供希望获得更直接交互方式的用户参考。

## 使用前要知道

这是交互偏好与工作流辅助，不是医疗建议或治疗方案。用户应按自己的需求调整规则，而非依赖统一模板。

## 上游明确提供的接入方式

上游提供 Claude Code 插件市场方式和标准 `SKILL.md`；虽然结构可被其他 Agent 读取，但未单独核验 Codex。
