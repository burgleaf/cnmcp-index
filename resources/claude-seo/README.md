# Claude SEO

> 本页依据 [Claude SEO 原仓库](https://github.com/AgriciDaniel/claude-seo) 整理；审计规则和安装方式以原仓库为准。

## 它解决什么问题

Claude SEO 把技术 SEO、内容质量、结构化数据、GEO、本地 SEO 与国际化检查组合成 Claude Code 可执行的工作流，帮助团队系统地发现网站可见性问题。

## 核心能力

- 检查抓取、索引、页面结构和常见技术 SEO 问题
- 分析内容质量、关键词覆盖和搜索意图
- 审查结构化数据、本地与国际化 SEO
- 生成面向修复和汇报的分析结果

## 适合谁

适合运营内容网站、产品官网或客户站点的营销人员、内容创作者和 Web 开发者。

## 使用前要知道

自动审计不能替代 Search Console、真实抓取数据与业务转化分析。涉及站点修改时，应先在测试环境验证。

## 上游明确提供的接入方式

上游将当前仓库定义为 Claude Code 插件并提供插件市场流程；它提到的 Codex 版本位于另一个独立仓库，不应视为本仓库已核验支持。
