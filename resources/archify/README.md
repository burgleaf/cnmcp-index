# Archify

> 本页依据 [Archify 原仓库](https://github.com/tt-a1i/archify) 整理；最新能力以原仓库为准。

## 它解决什么问题

Archify 让 AI 把代码仓库或系统描述转换成可以检查、修改和导出的架构图，帮助团队更快理解系统边界、数据流和关键交互。

## 核心能力

- 从现有代码与文字描述提取组件和关系
- 生成架构图、流程图与时序图
- 支持对图中结构继续追问、修订和验证
- 输出适合文档、评审或沟通的可交互结果

## 适合谁

适合需要梳理陌生代码库、编写架构文档、评审系统设计的开发者、架构师与产品经理。

## 使用前要知道

自动生成的图反映的是工具从输入中推断出的结构，不能替代对运行时依赖和业务边界的人工核验。
