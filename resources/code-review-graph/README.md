# Code Review Graph

> 本页依据 [Code Review Graph 原仓库](https://github.com/tirth8205/code-review-graph) 整理；语言支持和配置以原仓库为准。

## 它解决什么问题

Code Review Graph 用 Tree-sitter 建立代码关系图，让 AI 在审查变更时看到符号、调用和影响范围，而不是只依赖当前文件的局部文本。

## 核心能力

- 增量解析代码并维护符号关系图
- 通过 MCP 提供影响范围、依赖与相关上下文
- 辅助识别跨文件风险和潜在回归
- 减少为了理解改动而加载无关代码

## 适合谁

适合审查中大型代码库、分析跨模块修改，或希望提高 AI 代码审查上下文精度的开发者与团队。

## 使用前要知道

静态关系图不能覆盖所有动态行为、反射和运行时配置。高风险修改仍需结合测试、运行日志与人工审查。

## 上游明确提供的接入方式

上游安装器明确支持 Claude Code 与 Codex，并为对应客户端写入 MCP 配置。运行前请检查安装脚本和所需权限。
