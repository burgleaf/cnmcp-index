# AgentMemory

> 本页依据 [AgentMemory 原仓库](https://github.com/rohitg00/agentmemory) 整理；功能、安装参数和兼容性以原仓库最新说明为准。

## 它解决什么问题

AI 编程助手通常会在新会话中遗忘历史决策。AgentMemory 提供跨会话的持久记忆层，把对话、代码上下文和重要结论保存并按需检索，减少重复解释项目背景。

## 核心能力

- 自动捕获会话中的重要信息并压缩为可检索记忆
- 通过 MCP 工具搜索、读取和管理记忆
- 提供按需加载的记忆 Skills，避免一次性塞入全部上下文
- 支持本地优先存储，适合重视数据边界的开发团队

## 适合谁

适合长期维护同一代码库、经常跨会话协作，或希望让多个 AI 工作流共享项目知识的开发者与团队。

## 使用前要知道

记忆系统会影响后续生成结果。接入前应确认保存范围、敏感信息处理方式和清理机制，并定期检查过期或错误记忆。
