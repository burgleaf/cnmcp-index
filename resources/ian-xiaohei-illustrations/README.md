# Ian 小黑正文配图 Skill

> 本页依据 [Ian 小黑正文配图 Skill 原仓库](https://github.com/helloianneo/ian-xiaohei-illustrations) 整理；视觉样式与依赖以原仓库为准。

## 它解决什么问题

该 Skill 为中文文章、帖子和知识文档生成统一风格的正文配图，重点是 16:9、白底、手绘和小黑怪诞视觉语言。

## 核心能力

- 从正文提炼适合视觉表达的关键概念
- 生成适合文章段落之间插入的 16:9 图片
- 保持白底手绘与统一角色风格
- 服务于写作、知识分享和社交内容制作

## 适合谁

适合中文内容创作者、插画师、编辑和需要稳定文章配图风格的团队。

## 使用前要知道

生成图片应检查文字、事实表达和版权风险。品牌或商业发布前，还需确认所用图像模型的许可和内容政策。
