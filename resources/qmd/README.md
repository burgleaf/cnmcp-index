# QMD MCP

> 本页依据 [QMD 原仓库](https://github.com/tobi/qmd) 整理；索引方式和查询语法以原仓库为准。

## 它解决什么问题

QMD 在本地索引 Markdown 文档、知识库和会议记录，并通过关键词、向量与混合检索为 AI Agent 提供相关上下文。

## 核心能力

- 建立本地 Markdown 内容索引
- 支持关键词、向量和混合检索
- 按查询返回相关文档片段
- 通过 stdio 或 HTTP MCP Server 暴露知识库

## 适合谁

适合管理大量笔记、研究资料、会议记录和项目文档的研究者、内容创作者与团队。

## 使用前要知道

本地索引可能包含隐私和商业信息，应确认索引目录、模型或嵌入服务的数据边界，并设置合理的更新与删除流程。

## 上游明确提供的接入方式

上游提供 Claude Code 插件和手动 MCP 配置；通用 stdio/HTTP 服务可供其他客户端使用，但未单独核验 Codex。
