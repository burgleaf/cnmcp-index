# Plannotator

> 本页依据 [Plannotator 原仓库](https://github.com/backnotprop/plannotator) 与 [官方安装文档](https://docs.plannotator.ai/open-source/start/installation) 整理。

## 它解决什么问题

Plannotator 把 AI 生成的计划、文档和代码差异放到本地浏览器中批注，让用户能逐段反馈，再把结构化意见送回编码助手继续修改。

## 核心能力

- 在浏览器中阅读和批注计划与文档
- 对代码差异添加针对性反馈
- 将批准、拒绝和修改意见结构化返回 Agent
- 本地优先运行，适合评审敏感项目内容

## 适合谁

适合需要认真评审 AI 计划和改动的开发者、产品经理与软件团队。

## 使用前要知道

批注工具改善的是沟通界面，不会自动证明实现正确。代码仍需测试、安全检查和最终人工验收。

## 上游明确提供的接入方式

上游文档说明通过 Hooks、Skills 和命令接入 Claude Code，并明确提供 Codex 的命令和 Skill 交互方式。
