# Superpowers

> 本页依据 [Superpowers 原仓库](https://github.com/obra/superpowers) 整理；Skill 与插件版本以原仓库为准。

## 它解决什么问题

Superpowers 用可组合 Skills 和强制工作流约束 AI 编程过程，从需求澄清、设计和计划开始，再进入测试驱动实现、审查和交付。

## 核心能力

- 在编码前澄清需求并形成设计
- 把方案拆成可验证的实现步骤
- 推动测试驱动开发、调试和代码审查
- 在完成前执行验证与交付检查

## 适合谁

适合希望减少 AI 直接写代码造成返工，并建立稳定工程纪律的开发者与软件团队。

## 使用前要知道

严格流程会增加简单任务的成本，应按变更风险选择合适 Skill。任何“完成”结论都应由真实测试和代码状态支持。

## 上游明确提供的接入方式

上游已提供 Claude Code 与 Codex 的插件市场安装说明，也包含 Codex App/CLI 相关入口。
