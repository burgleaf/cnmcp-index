# PPT Master

> 本页依据 [PPT Master 原仓库](https://github.com/hugohe3/ppt-master) 整理；导出能力和依赖以原仓库为准。

## 它解决什么问题

PPT Master 让 AI Agent 把主题、文档或已有演示稿转换成可编辑 PPTX，重点保留原生形状、图表、表格、动画和旁白等演示文稿能力。

## 核心能力

- 从主题或长文档规划演示结构
- 生成可编辑的 PPTX 页面元素
- 使用图表、表格、动画与演讲者备注
- 基于已有演示稿继续整理或重构

## 适合谁

适合制作课程、汇报、提案和内容演示的教育者、内容创作者与业务团队。

## 使用前要知道

导出后应在目标 Office 软件中检查字体、版式、动画和跨平台兼容性。数据与结论也需要人工核验。
