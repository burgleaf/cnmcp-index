# Book to Skill

> 本页依据 [Book to Skill 原仓库](https://github.com/virgiliojr94/book-to-skill) 整理；转换规则和支持格式以原仓库为准。

## 它解决什么问题

Book to Skill 把技术书籍、文档目录或多份资料整理为可按需加载的 Agent Skill，让 AI 不必一次吞下整本资料，也能在需要时调用对应章节的知识和决策规则。

## 核心能力

- 分析长文档的章节、主题与知识边界
- 生成标准化 Skill 结构和入口说明
- 将事实、流程与决策规则组织为可检索内容
- 支持从多份资料构建一个面向特定任务的知识 Skill

## 适合谁

适合把内部手册、课程资料、技术书籍或研究笔记转成 AI 可用知识包的教育者、研究者和开发团队。

## 使用前要知道

请确认你有权处理输入资料。自动转换结果应抽查事实、章节映射和引用，避免把原文错误或过期结论固化为 Skill。

## 上游明确提供的接入方式

上游 README 提供 Claude Code Skill 安装路径，并说明产物遵循 Agent Skills 结构；未单独核验的宿主应按其 Skill 规范导入。
