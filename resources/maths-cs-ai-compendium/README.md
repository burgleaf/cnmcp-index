# Maths, CS & AI Compendium MCP

> 本页依据 [原仓库](https://github.com/HenryNdubuaku/maths-cs-ai-compendium) 整理；教材范围和运行要求以原仓库为准。

## 它解决什么问题

该项目把数学、计算机科学与人工智能教材组织为本地知识库，并通过 MCP 工具让 AI 助手查询，适合在学习和研究时获得基于指定材料的回答。

## 核心能力

- 索引数学、计算机科学和 AI 学习资料
- 按问题检索相关章节与知识片段
- 通过 MCP 向 AI 助手提供本地知识上下文
- 支持围绕教材进行解释、复习与研究

## 适合谁

适合学生、教育者、研究者，以及希望让 AI 依据本地教材回答问题的自学者。

## 使用前要知道

知识覆盖取决于已导入材料，回答仍需核对原教材。请确认教材的版权与本地使用权限，不要将受限内容公开分发。

## 上游明确提供的接入方式

上游 README 明确说明内置 MCP Server 可供 Claude Code 使用；虽然服务采用通用协议，但未单独核验 Codex 配置。
